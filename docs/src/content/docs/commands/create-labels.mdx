---
title: "auto create-labels"
---

Create your project's labels on github. If labels exist it will update them.

## Options

| Flag              | Type    | Description                                                 |
| ----------------- | ------- | ----------------------------------------------------------- |
| `--dry-run`, `-d` | Boolean | Report what command will do but do not actually do anything |

## Examples

```bash
auto create-labels
```

> [!warning]
> For this to work you must have a \`GH_TOKEN\` set, ex: \`GH_TOKEN=YOUR_TOKEN auto create-labels\`
