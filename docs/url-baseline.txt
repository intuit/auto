# URL baseline for the docs site, relative to the /auto base.
#
# Every path here must still be served after the move to Astro Starlight.
# Page paths (no extension) must resolve both bare and with ".html", the way
# GitHub Pages serves the old Next export. Paths with an extension are static
# files that must exist exactly.
#
# Produced from commit b0433e9d9 by building the packages, running the generator and
# running the Ignite build, then listing the routes in Next's pages manifest.
# The Ignite export itself fails on /blog under Node 26 (a JSON.parse of an
# unset env var inside next-ignite), so the manifest is the source of routes.
#
# Left out on purpose:
# - /docs/_sidebar: the sidebar source rendered as a page by accident.
# - /search-index.json: Ignite's search index, replaced by Pagefind.
#
# Kept beyond pages:
# - /blog/feed.xml: the blog's RSS feed.
# - /sw.js: the old site's PWA service worker; it must be replaced, not dropped.
# - Files in the public folder that content or READMEs link to by URL.
